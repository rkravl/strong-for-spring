STRONG FOR SPRING PWA

Upload all seven files to the root of a GitHub repository. Enable GitHub Pages under Settings > Pages > Deploy from branch > main > /(root). Wait for HTTPS site to publish. Open the URL in iPhone Safari, Share > Add to Home Screen. Open once online to cache files.

Edit exercises within the app by opening an exercise and tapping Edit, or Add exercise. Changes, notes and history are saved locally to the browser on that device. Export JSON regularly. Import JSON replaces the current device data. External video demonstrations require internet.

Do not open index.html directly from Files: the app uses fetch and a service worker, which require hosting.
